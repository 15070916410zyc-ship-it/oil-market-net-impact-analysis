# Visual benchmark: Light Data Terrain

Reviewed on 2026-08-23. The 50 references below are design evidence, not a
license to copy another brand. The implementation direction is a bright,
responsive data product whose motion explains oil-price flows, uncertainty and
risk.

## Chosen direction

- Canvas: mineral white (`#F4F8F7` / `#F5F7F2`) with deep ink (`#102622`).
- Data colors: teal (`#24796D`), ice blue (`#6EAFC6`), restrained lime
  (`#AFCF63`) and amber (`#E8B45B`). Red is reserved for a real warning.
- One site-wide ambient field: contour lines, flow paths, sparse nodes and soft
  light. There is no detached decorative illustration.
- Decision mode is a continuous story: situation, linked drivers, multiscale
  rhythm, forecast, risk, procurement cost and action.
- Professional mode opens the last-used tool directly. It has no intermediate
  landing page.
- Motion uses transform and opacity, pauses for reduced-motion users and is
  reduced on small screens.

## Motion and responsive limits

- Ambient cycle: 16–24 seconds; entry: 350–550 ms; chart transition:
  250–450 ms; hover: 120–180 ms.
- Pointer parallax is limited to 8 px and never moves text.
- No scroll hijacking, custom cursor, full-page WebGL or long opening loader.
- Test widths: 1440, 1024, 768, 430 and 390 px, both languages, both modes,
  reduced motion and keyboard navigation.
- Forecast history and forecast begin on one continuous path. The 50%, 80%
  and 95% ranges use color, opacity and line style so color is not the only cue.
